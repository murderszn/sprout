# Changelog

All notable changes to Sprout are documented here.

## v0.3.1 — 2026-09-07

### Website

- Rebuilt the landing hero around the supplied botanical, landscape, and bonsai artwork.
- Added a Sprout mark, stronger rounded structural containers, and a high-contrast forest, paper, pink, and yellow palette.
- Replaced the animated shader treatment with a static technical field and a real local-time Sprout clock, with an opt-in mechanical tick.
- Added the post “Agent Routers Make Clean Environments Non-Negotiable.”

### CLI

- Applied the site palette to terminal output: readable forest success states, paper text, yellow command and warning affordances, and pink error and dry-run states.
- Consolidated direct CLI status colors into the shared UI theme.

## v0.3.0

- Added device login, curated tool recipes, guarded install planning, and the initial Sprout documentation site.
