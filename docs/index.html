Ask the community ↗

Can I install a tool that isn’t listed?

Yes. The listed tools have curated installation and verification recipes. For other tools, Sprout uses your environment to reason through a plan and tells you it is working outside the curated library. Review the proposed commands before approving them.

What does Sprout cost?

Sprout is free and open source under the MIT license. AI inference runs through Pollinations and uses your Pollen balance. Usage depends on the model and the work needed for each run. Check your Pollinations account for your balance and current costs.

Why do I need a Pollinations account?

Pollinations provides the AI that turns your environment and errors into a plan. Run sprout login to authorize Sprout using your own Pollen balance. You can also configure your own Pollinations API key; see the setup documentation.

What can Sprout change on my machine?

Sprout can install tools and repair local configuration or PATH issues. It shows commands and asks for confirmation before system changes. Shell configuration edits are always shown and confirmed, with a backup of the previous file. Use sprout --dry-run install gh to preview commands without executing them.

Does it work on my operating system?

Sprout supports macOS, Linux, and Windows, with Node.js 20 or newer. It detects your shell and available package managers, then adapts the plan to your machine. Availability of individual tools can vary by platform.

What if an install still fails?

Run sprout diagnose --tool gh (replace gh with your tool), paste the failed command and its output, and finish with Ctrl-D on an empty line. Use sprout status to check your AI connection and sprout env to inspect environment detection. You can also share an issue through GitHub or the community.
